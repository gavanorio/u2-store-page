# U-2 Spyplane store page

Shopify section and product template for the Miltech Simulations U-2 Spyplane product page (theme: Impact).

- `sections/u2-spyplane.liquid`: the page
- `templates/product.u2-spyplane.json`: the product template
- `source/`: the prototype and the script that makes the section from it

The pictures are in the Shopify store (Content > Files, names start with `u2s_`).
